# VibeStream_YouTube_Clone
# 🎬 VibeStream – YouTube Clone

VibeStream is a beginner-friendly **YouTube Clone website** created using HTML and CSS.
The project is designed to practice webpage structure, styling, layouts, navigation bars, video cards, and responsive design.

## 📌 About the Project

VibeStream is a video-streaming website inspired by the basic layout and design of YouTube.

The project includes a homepage with a navigation bar, search section, sidebar, video thumbnails, and video information cards.

This project was created as a **frontend web development practice project**.

## ✨ Features

* 🎥 YouTube-style homepage
* 🔍 Search bar
* 📂 Navigation sidebar
* 🖼️ Video thumbnail cards
* 👤 Channel/profile information
* 📱 Responsive layout
* 🎨 Clean and simple user interface
* 🌐 Beginner-friendly HTML and CSS structure

## 🛠️ Technologies Used

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/bal-sunayana/VibeStream_YouTube_Clone.git
```

2. Open the project folder:

```bash
cd VibeStream_YouTube_Clone
```

3. Open `index.html` in your browser.

### Using VS Code

You can also open the project in **Visual Studio Code** and use the **Live Server** extension to run the website.
